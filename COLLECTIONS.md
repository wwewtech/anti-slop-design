  ```text
  Hey HN!

  Like many developers, I've noticed that whenever AI coding agents (Claude Code, Cursor, Windsurf) generate frontends, they predictably default to the same tired clichés:
  - Dark mode purple/indigo radial gradients blurred in corners
  - 3-card marketing grids with glowing borders
  - Raw emojis used as UI icons (🚀, 🔥)
  - Fabricated vanity claims ("+99.9% Uptime", "10x Faster")
  - Duplicate date-pickers inside individual widgets

  We built anti-slop-design (https://github.com/wwewtech/anti-slop-design), a single-file agent skill (SKILL.md) that acts as an autonomous Principal Design Technologist.

  It injects:
  1. The 1-to-3 UX rule (1 dominant action, max 3 secondary)
  2. 4 logic-preserving token archetypes (Quiet Luxury, Technical Terminal, Editorial, Tactile Obsidian)
  3. 8-state tactile micro-interactions (with Emil Kowalski's animation rules)
  4. An objective 7-axis pre-emit quality gate

  You can install it directly via Vercel's Skills CLI:
  $ npx skills add wwewtech/anti-slop-design

  Or for Claude Code:
  $ claude skills add https://github.com/wwewtech/anti-slop-design

  Live interactive demo & linter: https://wwewtech.github.io/anti-slop-design/

  Would love your feedback on the rules and archetypes!
  ```
