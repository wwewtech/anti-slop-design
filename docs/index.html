Core Commercial UX Laws SPEED & LOGIC

  • The 1-to-3 Rule
    1 dominant focal action per zone; maximum 3 secondary supporting actions. If a block has 5+ equal buttons, collapse into a popover or prioritize by frequency.
  • 85% Usage Law
    Identify the primary scenario used by 85% of users. Make it 1-click accessible. Tuck secondary 15% edge cases into subtle secondary menus.
  • Duplication Ban
    Exactly one brand mark in viewport. Exactly one global filter bar controlling the view. Never duplicate identical actions across header, sidebar, and cards.
  • Mobile Linearity
    Avoid placing competing complex logic blocks side-by-side on desktop. Stack sequentially so human eye scans without cognitive collision.

7-Axis Pre-Emit Quality Gate EVALUATION RUBRIC (>= 4/5 REQUIRED)

Evaluation Axis Objective Passing Standard
1. Anti-Slop Purity Zero purple radial blobs, zero raw emojis as icons, zero fake vanity stats, zero single-word italic gradients.
2. UX Speed & 1-to-3 1 primary action per zone, max 3 secondary, global filters at page header, zero duplicate KPI cards.
3. Typographic Scale Max 2 font families, tabular numbers enabled on all metrics, body line-length <= 75ch, sentence-case labels.
4. Geometric Math Strict 4px/8pt grid adherence, nested corner radius formula respected: R_inner = R_outer - Padding.
5. Micro-Interactions UI transitions < 200ms, high-frequency actions (100+/day) 0ms instant, tactile :active scale(0.97) present.
6. Accessibility (WCAG) Visible focus rings on all interactive elements (:focus-visible), aria-label on icon-only buttons, semantic HTML.
7. Mobile Linearity Clean vertical stacking, zero horizontal overflow bugs, touch targets >= 44px.
